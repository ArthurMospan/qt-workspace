# Лендінг QuickTeam

Окремий статичний сайт. Він **не є частиною застосунку**: не збирається разом
з ним, не імпортується ним і нічого в ньому не змінює.

Головне про нього — інтерфейс на сторінці справжній. Не «схожа на нашу»
картка задачі й не намальована дошка: розмітка взята з живого `/ui-kit`, а
стилі до неї згенеровані Tailwind'ом із того самого `src/app/globals.css`, що
й у продукті. Змінилася кнопка в застосунку — перезібрали лендінг, і вона
змінилася тут.

## Як відкрити

Подвійний клік по `index.html`. Збірки для перегляду не потрібно.

Один самодостатній файл (усе всередині, зовні тільки Google Fonts):

```bash
node Landing_claude/tools/bundle.mjs      # → dist/quickteam-landing.html
```

## Що всередині

| Файл | Що тримає |
| --- | --- |
| `index.template.html` | Сторінка з мітками `<!--shot:назва-->` замість інтерфейсу |
| `index.html` | Зібрана сторінка — **не редагується руками** |
| `assets/product.css` | Стилі продукту під цю розмітку — **генерується** |
| `assets/landing.css` | Токени, каркас, кнопки, шапка, герой, рама кадру, сцена |
| `assets/sections.css` | Секції сторінки, підвал, поява при скролі, вузькі екрани |
| `assets/landing.js` | Поведінка: шапка, нахил героя, поява, сцена на дошці, питання |
| `assets/mark.svg` | Знак QuickTeam (копія `public/logo-min.svg`) |
| `tools/` | Збірка, перевірка й зйомка |

Правити треба `index.template.html`, далі перезібрати. `index.html` і
`product.css` — результат.

## Як перезібрати

Потрібен піднятий `next dev` (сторінка `/ui-kit` віддає розмітку компонентів).

```bash
npm run dev                                # у сусідньому терміналі
node Landing_claude/tools/extract.mjs      # знімає розмітку з /ui-kit
node Landing_claude/tools/compose.mjs      # шаблон + розмітка → index.html
node Landing_claude/tools/styles.mjs       # index.html → assets/product.css
node Landing_claude/tools/bundle.mjs       # → dist/quickteam-landing.html
```

`extract.mjs` можна не ганяти щоразу — він пише `tools/kit-markup.json`, і
поки компоненти не змінювались, `compose.mjs` збирає з нього.

### Що робить `compose.mjs`

Каталог показує компоненти без даних, тому кадру потрібні дрібні правки, і
всі вони зібрані в одному місці — у таблицях на початку файлу:

- дати з каталогу давно минули, тож переставляються вперед (одна прострочена
  задача лишається навмисно: так буває);
- у сайдбарі немає проєктів і назви організації — організації ж не існує;
- посилання ведуть у нікуди, а керування не забирає фокус: кадр не клікають;
- превʼю з двома станами поруч (`keep`) і службові підписи для розробника
  (`drop`) на сторінку не йдуть.

Одна сцена руху додається теж тут: картка переїжджає з «До виконання»
в «У роботі». Відстань і висота слота не зашиті числом — їх міряє
`landing.js` по самій дошці, бо ширина колонки залежить від ширини вікна.

## Кольори

Сторінка темна — це колір сайдбару продукту (`#1f1f1f`), винесений на всю
поверхню. Ролі перевернуті: у застосунку `#1f1f1f` — це текст на світлому
полотні, тут це поверхня, а полотно `#f4f4f5` стало текстом. Мокапи всередині
лишаються світлими, бо продукт світлий.

Акценти — `#cf7a22` і `#0e8f74` — узяті з палітри графіків продукту
(`--color-chart-2` і `--color-chart-3`). Третього акценту немає навмисно.

Кнопки повторюють геометрію `Button.jsx` (36/32px, радіус 10px, поля 18px,
текст 13px) і міняють лише колір. **У UI Kit продукту нічого міняти не
треба** — ці правила живуть тільки тут.

Стилі сторінки написані поза `@layer` навмисно: так вони перебивають базові
правила продукту, зокрема `body`, якому застосунок задає висоту екрана
й заборону прокрутки.

## Перевірка

```bash
node Landing_claude/tools/check.mjs 1440   # і 1024, 768, 390
node Landing_claude/tools/check-bundle.mjs Landing_claude/dist/quickteam-landing.html
```

`check.mjs` міряє: горизонтальне переповнення, чи приземляється картка точно
в свій слот, чи не лишився блок невидимим після появи, чи не вилетів із кадру
компонент із `position: fixed`, і чи чиста консоль.

`tools/preview.mjs` знімає сторінку в кількох позиціях скролу, якщо треба
подивитись очима:

```bash
MARKS='[["top",0],["board",640]]' node Landing_claude/tools/preview.mjs ./out 1440
```

## Справжні знімки прода

`tools/capture.mjs` відкриває окреме вікно Chrome із власним профілем
(`tools/.profile`, ваш основний браузер не чіпає), чекає на вхід і зберігає
PNG екранів у `assets/shots/`. Знімати варто демо-організацію, а не робочий
простір: сторінка публічна.

Сьогодні сторінці це не потрібно — інтерфейс на ній і так справжній, — але
інструмент лишається для сторінок, де потрібен саме знімок.

Усі скрипти беруть Playwright і Tailwind із `node_modules` кореневого
проєкту. Це єдине, чим лендінг до нього дотикається, і тільки в інструментах
розробки: сама сторінка не залежить ні від чого.
